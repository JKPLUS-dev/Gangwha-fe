# Gangwha-fe 메인 와이어프레임 v0.1

범위: 강화 특산품 전용 멀티셀러 몰 (A안 상품 구성 + B안 업체 상점·입점·정산). 관광은 콘텐츠로만.
Design read: 신뢰감 있는 공공몰 + 산지직송의 따뜻함. 흰 바탕, 강조색 1개(갯벌·논 계열 녹/남색), 큰 상품 사진, 본문 16px+, 터치 44px+, 팝업·플로팅 레일 없음.

## 상세 첫 화면 필수 (테스트 대상)
원산지, 생산자, 배송 방식(냉장·냉동·상온), 예상 출고일, 도서산간 추가비, 재고/품절, 수량, 장바구니·바로구매(48px).

## 상태
메인 각 섹션: loading skeleton / 빈 데이터면 섹션 숨김 / 에러 시 "다시 불러오기" 버튼.

## 결정 필요
- 몰 이름·로고 (임시 "강화장터")
- 강조색 확정 (후보: 갯벌 남색 #1F4E5F 계열 / 논 녹색 #3F6B3A 계열)
